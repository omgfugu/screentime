Screen Time

Умный контроль экранного времени

Суть проекта: Комплексное Android-приложение для борьбы с цифровой зависимостью. Это не просто трекер, а полноценная экосистема для управления цифровым благополучием.

Зачем это нужно?

В современном мире мы проводим слишком много времени в экранах. Screen Time помогает осознанно подходить к использованию гаджетов, ограничивать отвлекающие факторы и дает родителям инструменты для контроля времени ребенка без тотальной слежки.

Ключевой функционал:

  • Аналитика: Точная статистика использования приложений на основе системного API.
  • Блокировка: Возможность выбора конкретных приложений и ограничения их запуска.
  • Таймер и PIN: Экран с обратным отсчетом. Разблокировка только по истечении времени или вводу кода.
  • Удаленный контроль: Интеграция с Firebase для отправки команд на блокировку с другого устройства.
  • OTA-обновления: Собственная система обновлений "по воздуху".
  • UI/UX: Строгий дизайн Liquid Glass, отзывчивый параллакс и эффекты при нажатии.

Техническая реализация:

Используются системные компоненты AccessibilityService и SYSTEM_ALERT_WINDOW. Firebase обеспечивает аутентификацию, облачное хранилище и Push-уведомления. Проект требует минимального Android 6.0 и настройки разрешений.
